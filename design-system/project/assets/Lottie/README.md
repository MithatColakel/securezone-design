# Lottie

The Lottie animations, copied verbatim from `native/App/Resources/lottie/` (played by `NSLottieView`). They are JSON data; the page lists them, it does not play them.

| File | Use |
|---|---|
| Gift.json | Bundled; not referenced by the app (`LottiePlayer.swift`: only three files are used) |
| JSON.json | Splash logo animation: 241 frames at 60 fps, played once at 1.5× (SplashView) |
| Lottie.json | Bundled; not referenced by the app (`LottiePlayer.swift`: only three files are used) |
| Lottie_Gift_Revision.json | VideoGiftPanel gift box |
| ProgressBarNoblackshapes.json | Bundled; not referenced by the app (`LottiePlayer.swift`: only three files are used) |
| ProgressBarNogradient.json | VideoGiftPanel 4-step progress bar, driven by progress |
| ProgressBar_Revised.json | Bundled; not referenced by the app (`LottiePlayer.swift`: only three files are used) |

Not copied: `assets/advertisement_video.mp4` (ad content).
